# One Advisory: Submission Kit

## One-liner

One Advisory turns one authorized drinking-water warning into three facility-specific, verified
responses—without letting AI issue guidance, close facilities, or allocate scarce resources.

## Four-minute spine

| Time | Demonstration |
|---|---|
| 0:00–0:30 | Warning delivery is not operational completion; state the authority boundary |
| 0:30–1:00 | Activate an existing fictional advisory and discover three facility classes |
| 1:00–1:35 | Inspect nine source-backed proposals and reject unsupported close-all policy |
| 1:35–2:05 | Named human approves sandbox delivery; facilities respond differently |
| 2:05–2:40 | Surface the last-water-slot conflict; show AI selected nobody; human allocates |
| 2:40–3:10 | Escalate school non-response, then process authorized rescission and recovery |
| 3:10–3:35 | Open registry, audit history, sources, safeguards, and proof suite |
| 3:35–4:00 | Show Cloud Run/Firestore/Vertex evidence, limits, and differentiation |

Required release proof: public Cloud Run URL, live Gemini recording and truth-set report, passing
deployed demo, architecture, public repository, short video, and explicit synthetic/non-endorsement
labels.
