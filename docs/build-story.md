# One Advisory: proving response after notification

I created this piece of content for the purposes of entering the All Things Agentic Hackathon.

One warning does not create one operational reality. A dialysis clinic, school, and long-term-care facility need different source-bearing work. One Advisory starts with an already-authorized synthetic drinking-water advisory, discovers three facility playbooks, requires a named official to approve instructions, gathers evidence, surfaces a scarce-resource conflict without allocating it, escalates silence, and verifies recovery.

Four capabilities are live in Google Cloud Agent Registry. Cloud Run hosts the response fleet, Gemini 3.5 Flash reads the synthetic advisory, Firestore persists incident and wake state, and Cloud Trace correlates requests. A missing source blocks unsupported tasks; failed contact never becomes a fake acknowledgement; ambiguous rescission never ends protections.

This tabletop uses fictional facilities and sandbox connectors. It proves architecture and execution, not health or response-time outcomes.
