# One Advisory cloud infrastructure

The checked-in composite indexes support transactional acknowledgement and recovery wake scans. The public service uses synthetic facility data and sandbox contacts only. A production scheduler endpoint must be authenticated and scoped to the worker service account.

## Managed discovery

Run `python infra/register_agents.py` to idempotently register four scoped REST capabilities. These entries describe the deployed Cloud Run service; they do not claim that the eight logical roles are separate services or identities.
